# 8. 企业生产实践

## 8.1 定价风波：订阅制与 token 成本的第一次正面相撞

2025-06-16，Cursor 把 Pro 计划从"每月 500 次 fast 请求"改为"$20 按 API 价计的额度池 + Auto 模式不限量"【一手：cursor.com/blog/june-2025-pricing】。按官方复盘：

- $20 额度约等于 225 次 Sonnet 4 / 550 次 Gemini / 650 次 GPT-4.1 请求（中位用量口径）；
- **沟通失误**：“unlimited usage”实际仅限 Auto 模式，官方承认"We were not clear"；
- 大量重度用户一周内烧穿额度并收到超额账单，社区反弹激烈；
- 2025-07 初 CEO Michael Truell 发文道歉（"We missed the mark"），全额退还 6 月 16 日至 7 月 4 日间的意外超额费用，并承诺：额度预警可视化、超额前宽限、提前公告。

这次风波是 AI SaaS 定价的经典案例：**固定订阅坐在变动 token 成本上，额度池是诚实的解法，但"诚实"必须与"预期管理"同频上线**。事后 Cursor 完整保留了额度池模式（并新增 $200 Ultra 档），说明其经济学判断没有动摇，动摇的是沟通链路。mini-demo 场景 5 的毛利悬崖（55% → 0%）正是这次风波的成本结构注脚。

## 8.2 与模型供应商的博弈：从"被求购"到"被断供"

时间线【全部为媒体报道，截至知识截止】：

1. 2024 年至 2025 年初：OpenAI 多次寻求收购 Anysphere 未果（TechCrunch 2025-04-17 报道），创始团队选择独立。
2. 2025 年：OpenAI 转购 Windsurf（约 $3B 意向）失败，Google 以约 $2.4B 挖走 Windsurf 核心团队，Cognition 接手剩余资产——AI 编程 IDE 独立生存的结构性困难公开化。
3. 2026 年 SpaceX 收购后：据 TechCrunch 等媒体 2026 年 8 月报道，OpenAI 通知将于 2026-11-12 终止对 Cursor 的模型访问；同期 Anthropic 被报道将加大对 Cursor 的算力/模型支持。**截至本主题知识截止（2026-10-17），断供决定尚无双方一手公告，本主题将其标注为媒体报道。**

这条线索的 infra 含义：Cursor 的"模型无关 + Router"架构天然是对冲断供的——调度器后面挂谁不挂谁，是配置问题而非架构问题；但 frontier 质量层的可替换性有上限（官方 Composer 博客自己承认 Best Frontier 更强），所以 Composer 系列的持续投入（Composer 2 于 2026-03 发布技术报告、Composer 2.5 于 2026-05 上线【一手】）本质是把"供应商风险"逐步内化。

## 8.3 SpaceX 收购：算力接入与组织边界

已确证事实【TechCrunch 多篇一手报道】：2026-04 SpaceX 与 Cursor 签期权协议（$60B 收购权或 $10B 合作费）；2026-06-12 SpaceX IPO；2026-06-16 官宣 $60B 全股票收购；2026-08-14 交割，Cursor 强调获得 SpaceX 数据中心算力接入。交易时点 Cursor 年化收入约 $4B（媒体口径）。

对 Cursor 基础设施的可预期影响【推断】：推理成本最大的第三方依赖（frontier API + 商业推理云）部分转化为自有/关联算力；Composer 训练栈（官方口径已扩至数千张 NVIDIA GPU）获得第二供给源。需保持清醒的是：**收购整合、Grok 模型整合、定价体系调整等 2026 下半年事项，截至知识截止均无一手技术披露**，本主题不作展开。

## 8.4 隐私、合规与企业落地

一手可确证的实践：

- **隐私模式**：zero data retention 协议；索引不存明文（嵌入 + 混淆路径 + 行号）；隐私模式在 Teams/Enterprise 默认开启且管理员可强制【一手：安全文档】。
- **抓包争议**：社区项目证实索引期存在文件衍生数据上传、载荷不可判定【社区】——架构承诺与可审计性之间的落差，是企业采购时的真实评估点。
- **自我托管**：Self-Hosted Machines（2026-09）把工具执行与代码/构建缓存/密钥留在客户环境，worker 仅出站长连接；执行端可插拔（Cloudflare Sandboxes、E2B、Modal 等）【一手 + Cloudflare 新闻稿】——这把"代码不出域"从合规承诺变成了部署选项。
- **模型治理**：Router 管理端支持按团队灰度、模型黑白名单、默认档位——企业"哪些任务可用哪些模型"的治理需求被做成产品功能【一手：Router 博客】。

## 8.5 组织实践：小团队高杠杆

公司规模口径【媒体】：从 2022 年 4 人到 2025 年的数百人，支撑了 4 亿次/日的 Tab 请求与数千 GPU 的训练栈。公开访谈中创始团队反复强调的工程文化【一手访谈】：极短的反馈回路（1.5-2 小时 checkpoint 上线）、research 与 product 同仓协作（Composer 训练栈与产品沙箱共用 VM 调度器）、以及对"直接可测指标"（接受率、keep rate）的执念。这种组织形态与 xAI 的"速度优先"有相似之处，但 Cursor 的速度体现在**部署频率**而非硬件堆叠上（对照 [xAI 案例](/09-case-study/xai/)）。
